# 公式辞典（韓国語基礎辞典）のデータ

国立国語院「韓国語基礎辞典」（한국어기초사전）の「辞書全体ダウンロード」の形式と、実測した数字の記録です。
取り込み・初期投入の作業（`docs/tasks/01`〜`04`）で参照します。

- 音声・画像などのマルチメディア: ファイルごとに条件が違うため **取り込まない**
- 出典は「このアプリについて」ページにまとめて表示する

## ファイル

`전체_내려받기_한국어기초사전_json_20260919.zip`（約84MB）を展開すると、`1_5000_20260919.json` 〜 `11_3671_20260919.json` の11ファイル（計約1GB、見出し語の音順）。

形式は LMF（Lexical Markup Framework）を JSON にしたものです。`LexicalResource.Lexicon.LexicalEntry[]` が見出し語の一覧です。
値は `{"att": 名前, "val": 値}` の形で `feat` に入っています。**1件のときは配列ではなくオブジェクトになる**ので、両方を扱ってください。

| 欲しい情報 | 入っている場所 |
|---|---|
| 識別コード（API の `target_code` と同じ） | エントリ直下の `att: "id"` の `val` |
| 見出し語 | `Lemma.feat` の `writtenForm` |
| 同形語番号・品詞・等級 | エントリの `feat` の `homonym_number`・`partOfSpeech`・`vocabularyLevel`（ほかに `lexicalUnit`、`semanticCategory`、`subjectCategiory`※綴りママ） |
| 発音 | `WordForm`（`type: 발음`）の `pronunciation` |
| 活用形 | `WordForm`（`type: 활용`）の `writtenForm` と `pronunciation`（発音は複数の場合・無い場合がある） |
| 語義 | `Sense[]`。語義番号は `Sense` 直下の `att: "id"`。韓国語の語義は `feat` の `definition` |
| 日本語訳 | `Sense[].Equivalent[]` のうち `language: 일본어` の `lemma`（訳語）と `definition`（語義の訳） |
| 取り込まないもの | `sound`（音声URL）、`Multimedia`、`SenseExample`（例文） |

### 例: 괜찮다（識別コード 60097）

- 発音: [괜찬타]
- 活用形: 괜찮은 [괜차는]、괜찮아 [괜차나]、괜찮으니 [괜차느니]、괜찮습니다 [괜찬씀니다]、괜찮고 [괜찬코]、괜찮지 [괜찬치]
- 語義1「꽤 좋다」→ なかなかいい
- 語義2「별 문제가 없다」→ だいじょうぶだ【大丈夫だ】

### 注意点

- **語義番号と並び順は一致しないことがある**（例: 사랑하다（62743）の語義は 1, 2, 5, 3 の順に並んでいる）
- **同じ綴りの別の語がある**（例: 네＝「はい」と「お前」、최고＝「最高」と「最古」、먹다＝「食べる」と「耳が遠くなる」）
- **第1語義が想定した意味とは限らない**（例: 괜찮다 の「大丈夫だ」は第2語義）
- 活用形は「-는／-ㄴ」「-아／어」「-니」「-ㅂ니다」の4種類程度しかない。**하다 動詞・形容詞は「-하여」の形**で入っていて、口語の「-해」は無い

## ドラマ頻出89語での照合

| 結果 | 語数 | 例 |
|---|---|---|
| 見出し語として一致 | 34 | 진짜、대박、아이고、오빠、누나、설마、제발 |
| 公式の活用形として一致 | 16 | 감사합니다 [감사함니다]、고마워、괜찮아 [괜차나]、몰라、귀여워 |
| 公式の活用形＋「요」で一致 | 4 | 괜찮아요、맛있어요、반가워요 |
| 見つからない | 35 | 사랑해、미안해、안녕하세요、잘 자、헐、화이팅 |

- 見つからない語の大半は、基本形は収録されていて口語の活用形が無いだけ（사랑해 ← 사랑하다、미안해 ← 미안하다、안녕하세요 ← 안녕하다、가자 ← 가다）
- 基本形も無い語: 헐、화이팅／파이팅、짜증나다
