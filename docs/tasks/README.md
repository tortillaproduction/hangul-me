# 作業指示書: 公式辞典による辞書の構築と、あいまいな読みに強い検索

このディレクトリの指示書は、次の2つを実現するための作業を、**1ファイル＝1ブランチ＝1つのPR** に分けたものです。

1. **辞書DBに入る単語を、すべて国立国語院「韓国語基礎辞典」で確認できる正確なものにする**
2. **うろ覚えの読みがあいまいでも、正しいハングルが候補に出るようにする**

どちらも Hangul-me の存在意義そのものです。見た目より「正確なハングルが、正解として候補に入るか」を最優先にしてください。

## すべての指示書に共通する決まり

- 作業を始める前に `CLAUDE.md` と `docs/ubiquitous-language.md` を読む
- 指示書と `CLAUDE.md` が食い違う場合は `CLAUDE.md` を優先し、食い違いを報告する
- **🛑 の付いた手順では作業を止め、ユーザーに確認を依頼する。** 確認なしに先へ進めない
- 各指示書の「ドキュメント」の項は、そのPRの中で済ませる（`CLAUDE.md` の「変更したらドキュメントも更新する」）
- マイグレーションは追記のみ。既存のファイルは書き換えない

## 元データの置き場所

国立国語院「韓国語基礎辞典」の「辞書全体ダウンロード」の ZIP（約84MB）を、リポジトリ直下の `data/krdict/` に置きます。

```
data/krdict/전체_내려받기_한국어기초사전_json_20260919.zip
```

`data/` は Git で追跡しません（01 で `.gitignore` に追加します）。

## 全体を通してやらないこと

- **公式辞典に見出し語が無い語の収録**（헐、화이팅 など）。一覧にして報告するだけ
- 複数の語からなる言い回し（잘 자、정신 차려 など）の収録。各語が公式辞典にあっても、言い回しとしての意味は公式ではないため。別タスクで扱いを決める
- 例文の取り込み（公式辞典の例文には日本語訳が無いため）
- 音声・画像データの取り込み（ライセンスの条件が別のため）
- 検索ログから読みの別表記を自動で育てる仕組み
- 各指示書に書いた以外のUIの変更
