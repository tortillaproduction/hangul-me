# 04. 初期投入

- ブランチ: `feat/krdict-seed`
- 前提: 03 がマージ済み
- 参照: [../krdict-data.md](../krdict-data.md)、共通の決まりは [README.md](README.md)

## 目的

**ドラマや映画で耳に残りやすい語** を、公式辞典から300〜500項目（見出し語×語義）選んで辞書に入れます。
人が決めるのは「どの見出し語の、どの語義の、どの形を使うか」だけです。ハングル・読み・意味は書きません。

---

## 1. 用語を追加する（実装より先）

`docs/ubiquitous-language.md` に追加し、変更履歴に1行追記します。

| 用語 | コード上の名前 | 意味 |
|---|---|---|
| 初期投入 | `seed` | サービス開始前に、確認済みの単語を辞書へまとめて入れること |
| 選定ファイル | `selection.json` | 初期投入する見出し語・語義・形の一覧。人が編集する唯一のファイル |

## 2. 選定ファイル

`db/seed/krdict/selection.json`

```json
[
  {
    "krdict_id": 60097,
    "sense_no": 2,
    "forms": ["괜찮아", "괜찮아요", "괜찮습니다"],
    "category": "感情・状態"
  },
  {
    "krdict_id": 62743,
    "sense_no": 1,
    "forms": ["사랑해", "사랑해요", "사랑합니다"],
    "category": "感情・状態"
  }
]
```

（괜찮다 は 60097 の語義2「大丈夫だ」、사랑하다 は 62743 の語義1「愛する」）

- `forms` の各要素は、見出し語そのもの・公式の活用形・02 の規則で作れる形のどれか
- **同じ綴りの別の語に注意する**（네＝「はい」と「お前」、최고＝「最高」と「最古」、먹다＝「食べる」と「耳が遠くなる」）
- **語義も選ぶ**。第1語義が期待した意味とは限らない（괜찮다 の「大丈夫だ」は第2語義）
- 語義番号は並び順と一致しないことがある。必ず参照テーブルの `sense_no` を使う

## 3. 収録する語彙

300〜500項目。網羅性より、よく聞く語を正しく揃えることを重視してください。

- 候補の母集団: 公式辞典の初級・中級（11,613語。日本語訳・発音がほぼ揃っている）
- カテゴリの目安: 挨拶・礼、感嘆・相づち、呼びかけ・呼称、感情、日常の動詞・形容詞（よく聞く活用形で）、疑問・指示
- 03 で消えた開発用シード15件の語（안녕、안녕하세요、진짜、사랑해、오빠、언니、감사합니다、맛있어요、대박、괜찮아요、보고 싶어、알겠습니다、미안해、화이팅、어떻게）は、入れられるものはすべて入れる。入れられないものは理由を付けて PR で報告する
  - 見込み: 화이팅 は公式辞典に見出し語が無い。보고 싶어 は複数の語からなる言い回し（[README.md](README.md) の「やらないこと」）。알겠습니다（-겠-）と 어떻게（-게）は 02 の規則に無い形なので、見出し語として載っていなければ入らない
- **公式辞典に見出し語が無い語は入れない。** 一覧にして PR で報告する

## 4. 生成ツール

`backend/cmd/seedgen` を追加します。

```bash
cd backend
go run ./cmd/seedgen            # selection.json から dictionary_entries を作り直す
go run ./cmd/seedgen -check     # 検証だけして、DBは変えない
go run ./cmd/seedgen -review    # 確認用の一覧（Markdown）を出力する
```

- 各形を 03 の `domain/dictionary` に通して `entry.Entry` を作る（**このツールで独自に組み立てない**）
- 1件でも組み立てに失敗したら全体を失敗させ、失敗した項目と理由をすべて表示する
- 投入は1つのトランザクションで行い、何度実行しても同じ結果になること
- 単語帳から参照されている単語は消さない。`selection.json` から外された単語が単語帳で使われていたら、エラーにして報告する

## 5. 🛑 人の確認

`seedgen -review` の一覧を、カテゴリごとにユーザーに確認してもらいます。

| ハングル | 基本形 | 語義（日本語訳） | カナ読み | 発音の出どころ | 備考 |
|---|---|---|---|---|---|
| 괜찮아요 | 괜찮다 | 大丈夫だ | ケンチャナヨ | 公式＋요 | |
| 먹자 | 먹다 | 食べる | モクチャ | 規則 | ⚠ 規則で作った発音 |

- **規則で作った発音**と、**同じ綴りの別の語がある語**には ⚠ を付け、確認してほしい理由を添える
- 指摘は `selection.json`（または 02 の正解表・例外）に反映して `seedgen` を再実行する。生成結果を手で直さないこと
