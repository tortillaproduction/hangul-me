## 2. 公式の発音からカナ読みを作る

**このシリーズでいちばん正確さが問われる部分です。**
公式の発音（音の変化をすでに反映したハングル）を、1音節ずつカナに置き換えます。連音化・鼻音化などの発音規則は公式の発音側で済んでいるので、ここでは実装しません。

### 置き場所

`internal/domain/hangul/kana.go` に `PronunciationToKana(pron string) string` を追加します（`Decompose` を使う）。
ひらがなは、既存のカタカナ→ひらがな変換で作ります。

### 変換の方針（初期案）

日本の学習書でよく使われる書き方に合わせます。**迷ったら下の正解表を優先**してください。

- **初声**
  - ㄱ・ㄷ・ㅂ・ㅈ は、語頭では清音（カ・タ・パ・チャ）、語中（母音・ㄴ・ㄹ・ㅁ・ㅇ の後）では濁音（ガ・ダ・バ・ジャ）
  - 激音（ㅋ・ㅌ・ㅍ・ㅊ）は常に清音
  - 濃音（ㄲ・ㄸ・ㅃ・ㅆ・ㅉ）は清音。直前が母音なら「ッ」を前に付ける（오빠 → オッパ）
  - ㅇ は母音だけ（ア行）
- **母音**: ㅓ と ㅗ はどちらも「オ」、ㅡ と ㅜ はどちらも「ウ」、ㅐ と ㅔ はどちらも「エ」。二重母音は「ワ・ウォ・ウェ・ウィ」など
- **パッチム**
  - ㄴ・ㅇ → ン、ㅁ → ム、ㄹ → ル
  - ㄱ → ク、ㄷ → ッ（語末はト）、ㅂ → プ
  - ㄱ・ㄷ・ㅂ の直後が同じ系統の子音（濃音・激音）なら「ッ」（학꾜 → ハッキョ）

### 正解表（ゴールデンテスト）

`internal/domain/hangul/testdata/kana_golden.json` に「公式の発音 → 期待するカナ・ローマ字」を **50件以上** 作り、Ginkgo の `DescribeTable` で全件一致を確認します。最低限、次を含めること。

| 語 | 公式の発音 | 期待するカナ |
|---|---|---|
| 감사합니다 | 감사함니다 | カムサハムニダ |
| 괜찮아 | 괜차나 | ケンチャナ |
| 고마워 | 고마워 | コマウォ |
| 진짜 | 진짜 | チンチャ |
| 오빠 | 오빠 | オッパ |
| 대박 | 대박 | テバク |
| 맛있어 | 마시써 | マシッソ |
| 아이고 | 아이고 | アイゴ |
| 안녕 | 안녕 | アンニョン |

- 괜찮아 の ㅙ は、原則どおりなら「クェンチャナ」ですが、日本語の学習書では「ケンチャナ」が一般的です。このような**原則と慣用がずれる語は、正解表で個別に決めて、変換表に例外として持たせる**
- 正解表には、選んだ理由が要る行（例外・迷った行）に `note` を付ける

🛑 **正解表をユーザーに確認してもらってください。** カナの書き方の好みが入るところなので、勝手に決めないこと。

### ローマ字

`PronunciationToRomanized(pron string) string` も同じ場所に作ります。公式の発音から、国語のローマ字表記法に沿った音節ごとの対応表で作ります。正解表に `romanized` の列を足してください。

## 3. 規則で活用形を作る

公式辞典の活用形は「-는／-ㄴ」「-아／어」「-니」「-ㅂ니다」の4種類程度で、**하다 動詞・形容詞は「-하여」の形**で入っています。ドラマで聞く口語の形は、規則で作ります。

### 置き場所

`internal/domain/conjugation/` に、見出し語と公式の活用形を受け取って、活用形とその発音の一覧を返す関数を作ります。

### 作る形

| 種類 | 例 | 作り方 |
|---|---|---|
| 반말（-아／어） | 사랑해、가 | 公式の「-아／어」形。하다 は「하여 → 해」に縮める |
| 해요体 | 사랑해요、괜찮아요 | 반말 ＋ 요 |
| 합니다体 | 감사합니다 | 公式の「-ㅂ니다」形をそのまま使う |
| -세요 | 안녕하세요、가세요 | 語幹 ＋ (으)세요 |
| 過去の반말・해요体 | 사랑했어、사랑했어요 | 반말の母音に ㅆ を足して ＋ 어 / 어요 |
| -자 | 가자 | 語幹 ＋ 자 |
| -지 마 | 가지 마 | 語幹 ＋ 지 마 |

- 不規則活用（ㅂ・ㄷ・ㅅ・르・ㅎ など）は、**公式の「-아／어」形から逆算**して語幹の変化を拾う（고맙다 → 고마워 → 고마워요）
- 公式の「-아／어」形が無く、不規則活用の可能性がある語は、**生成を諦めてエラーにする**（推測で作らない）
- 生成した形の発音:
  - 公式の形に「요」を足すだけの形は、公式の発音に「요」を足す
  - それ以外は、語幹の末尾と語尾の先頭がつながる部分だけに音の変化の規則を当てる（例: 먹자 → [먹짜]）
  - どちらで作ったかを結果に持たせる（`official` ／ `official+yo` ／ `rule`）。04 の確認で使う

### テスト

- 上の表の各行
- 不規則活用の代表例（고맙다・듣다・모르다・낫다）
- 公式の「-아／어」形が無い語でエラーになること
